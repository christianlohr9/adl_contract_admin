## Directory Purposes

**app/**
- Purpose: All application source code
- Contains: Entry point, config, pages, services
- Key files: `main.py` (app entry point)

**app/config/**
- Purpose: Centralized configuration
- Contains: Database credentials, league constants, defaults
- Key files: `config.py` - `db_config` dict, `START_YEAR`, `LEAGUE_ID`, `DEFAULT_SEASON`

**app/pages/**
- Purpose: Taipy UI page definitions
- Contains: String-based markup for each route
- Key files: `home.py`, `extension.py`, `evp.py`

**app/services/**
- Purpose: Business logic, data access, external integrations
- Contains: All functional logic modules
- Key files: `database_service.py` (DB ops), `epv_calculations.py` (core calculations), `data_processing.py` (filtering)

**app/data/**
- Purpose: Static data files
- Contains: SQL schema and seed data
- Key files: `dump.sql`

## Naming Conventions

**Files:**
- `snake_case.py` for all Python modules (`database_service.py`, `data_processing.py`)
- `__init__.py` for package markers
- Descriptive names matching purpose

**Directories:**
- Lowercase, plural for collections: `pages/`, `services/`
- Singular for concepts: `config/`, `data/`

**Special Patterns:**
- `d.py`, `d.ipynb` - Scratch/exploration files (should be cleaned up)
- `dump.sql` - Database export file

## Where to Add New Code

**New Page/Route:**
- Page markup: `app/pages/{page_name}.py`
- Route registration: `app/main.py` (pages dict)
- Event handlers: `app/main.py`

**New Service/Business Logic:**
- Implementation: `app/services/{service_name}.py`
- Import in: `app/main.py` or other services as needed

**New Configuration:**
- Constants: `app/config/config.py`
- Environment vars: `app/config/config.py` (via `os.getenv()`)

**New Data Processing:**
- Filters/transforms: `app/services/data_processing.py`
- Calculations: `app/services/epv_calculations.py`
- Database queries: `app/services/database_service.py`
