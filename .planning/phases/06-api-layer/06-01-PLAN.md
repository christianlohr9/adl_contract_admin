**src/app/api/teams.py** — Teams router (prefix="/api/teams", tags=["teams"]):
- `GET /` → list[TeamSchema] — Return all 32 teams. Simple select all, ordered by name.
- `GET /{team_id}` → TeamSchema — Single team by ID. 404 if not found.
- `GET /{team_id}/roster` → list[RosterEntrySchema] — Team roster for a season (query param `season: int`). Join RosterEntry → Player → Contract to build each entry with player name, position, salary, contract info. Filter by team_id + season. Order by salary desc. Use query param with default to current season (2026).
- `GET /{team_id}/contracts` → list[ContractSchema] — All contracts for a team in a season (query param `season: int`). Filter Contract by team_id + season. Order by salary desc.

**src/app/api/players.py** — Players router (prefix="/api/players", tags=["players"]):
- `GET /{player_id}` → PlayerWithContractSchema — Single player with their current active contract info. 404 if not found. Load player, then load their active contract for season (query param `season: int`, default 2026). If no contract, return player fields with contract fields as None.
- `GET /search` → list[PlayerSchema] — Search players by name substring (query param `q: str`, min length 2). Limit 50 results. Use ilike for case-insensitive search. Order by name. IMPORTANT: Define this route BEFORE `/{player_id}` to avoid path parameter conflicts.

**src/app/main.py** — Include both new routers alongside existing sync_router.

Use SessionDep for all endpoints. Use `select()` with appropriate joins/filters. Return 404 with `detail` message for missing resources using HTTPException.

Do NOT add pagination yet — rosters are max ~53 players, teams are 32. Keep it simple.
