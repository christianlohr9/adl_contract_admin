**Spreadsheet reference:**
- File: `2026 ADL Contract Admin.xlsx`
- Tab: `FT5YO $` — Positional salary table
  - Row structure: EFT*, NEFT, TT, 5YO+, 5YO-, then individual salary ranks (1-N)
  - Columns: QB, RB, WR, TE, PK/PN, DT, DE, LB, CB, S
  - Two sections: "February 15 Salaries" (left) and "July 1 Salaries" (right, col M+)
  - EFT row has asterisk (*) indicating it uses Feb 15 salaries; NEFT/TT use July 1 salaries
  - The left section (Feb 15) has EFT* values; the right section (July 1) has EFT/NEFT/TT values
  - Both sections should be compared for completeness

**Tag salary formulas (from bylaws):**
- EFT/NEFT: MAX(AVG(Top5 salaries at position), 1.20 × prev_salary), rounded to $10k
- TT: MAX(AVG(Top10 salaries at position), 1.20 × prev_salary), rounded to $10k
- Opening bid (NEFT/TT): MAX(CEIL_100K(SD_Min - 0.1), FLOOR_100K(tag_salary))
- PK and PN grouped into single "Kicker/Punter" category

**Key detail:** The spreadsheet's FT5YO $ tab shows the positional averages (the "base" tag price per position), NOT per-player prices (which also include the 120% floor). Validation must:
1. First validate that the app's positional averages match the spreadsheet's EFT/NEFT/TT rows
2. Then for each eligible player, verify the MAX(positional_avg, 1.20 × prev_salary) logic produces correct per-player tag prices

<task type="auto">
  <name>Task 1: Build FT price validation script</name>
  <files>scripts/validate_ft_prices.py</files>
  <action>
Create a CLI script that validates tag price calculations in two layers:

**Layer 1: Positional average validation**
1. Load FT5YO $ tab from spreadsheet using openpyxl
2. Extract the EFT, NEFT, TT positional averages for each position (QB, RB, WR, TE, PK/PN, DT, DE, LB, CB, S)
3. For each position, query the app's `_get_top_n_positional_salaries()` (top 5 for EFT/NEFT, top 10 for TT) and compute the average
4. Compare app's positional averages against spreadsheet values
5. Report any position-level discrepancies with expected vs actual and individual top-N salaries

**Layer 2: Per-player price validation**
1. For all FT-eligible players (from Plan 18-01's validation or re-query), call `calculate_franchise_tags()` to get EFT/NEFT/TT prices
2. Verify each player's tag salary = MAX(positional_avg, 1.20 × prev_salary)
3. For NEFT/TT, verify opening_bid = MAX(CEIL_100K(SD_Min - 0.1), FLOOR_100K(tag_salary))
4. Report any per-player price discrepancies

**Output:** Markdown report with:
- Positional average comparison table (position × tag type, expected vs actual)
- Per-player price spot-check results
- Discrepancy details with root cause analysis
- Opening bid verification for NEFT/TT

CLI args: --season (default 2026), --output (file path or stdout)

IMPORTANT: The spreadsheet has TWO salary sections — "February 15 Salaries" (columns B-K) and "July 1 Salaries" (columns N-W). Check which section the app's data aligns with (likely depends on when salary snapshots were taken). Document which section is being compared.
