<task type="auto">
  <name>Task 1: Build FT eligibility validation script</name>
  <files>scripts/validate_ft_eligibility.py</files>
  <action>
Create a CLI script following the Phase 17 pattern (scripts/validate_eligibility.py) that:

1. Loads all player rows from the TagElig26 tab of `2026 ADL Contract Admin.xlsx` using openpyxl (read_only=True, data_only=True)
2. For each row, extracts: player name, salary, years, FT eligibility (column H — "FT" or None)
3. Matches each spreadsheet player to the database by name. Player names in spreadsheet are formatted "Lastname, Firstname TEAM POS" — extract the "Lastname, Firstname" portion and match against Player.name in DB. Handle edge cases: some names may have suffixes (Jr., III, etc.)
4. For each matched player, calls `check_tag_eligibility(session, player_id, season)` directly from `app.services.franchise_tags` (NOT the unified check_eligibility, to bypass window gating)
5. Compares app result (eligible=True/False) against spreadsheet (FT="FT" or None)
6. Produces a structured markdown report:
   - Summary: total players, matched count, unmatched count, discrepancy count
   - Discrepancy table: player name, spreadsheet says, app says, app reason
   - Unmatched players list (spreadsheet players not found in DB)
   - Confidence statement

CLI args: --season (default 2026), --output (file path or stdout)

IMPORTANT: The spreadsheet bypasses window gating — it shows eligibility based purely on contract state. The validation script must also bypass window gating by calling check_tag_eligibility directly.

Name matching strategy: Strip the "TEAM POS" suffix from the spreadsheet player name by splitting on spaces and taking everything before the last 2 tokens (which are team abbreviation and position). Then match against Player.name using case-insensitive comparison. Log any unmatched players for manual review.
  </action>
  <verify>
    uv run python scripts/validate_ft_eligibility.py --season 2026 2>&1 | head -40
    Script runs without errors and produces a report with summary stats.
  </verify>
  <done>
    Script runs against live DB, matches >95% of spreadsheet players, and produces a clear discrepancy report. Zero crashes or unhandled exceptions.
  </done>
</task>
