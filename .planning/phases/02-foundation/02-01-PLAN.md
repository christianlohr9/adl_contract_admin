<task type="auto">
  <name>Task 2: Initialize new project scaffold with uv</name>
  <files>pyproject.toml, src/app/__init__.py, src/app/core/__init__.py, src/app/models/__init__.py, src/app/schemas/__init__.py, src/app/api/__init__.py, tests/__init__.py, .github/workflows/ci.yml</files>
  <action>
Initialize new project with uv:

1. Run `uv init --no-readme` to create pyproject.toml, then edit it:
   - name: "adl-contract-admin"
   - version: "0.1.0"
   - requires-python: ">=3.13"
   - Add dependencies: fastapi[standard], sqlalchemy[asyncio], asyncpg, alembic, pydantic-settings
   - Add dev dependencies: pytest, pytest-asyncio, httpx, ruff, mypy

2. Create src/ directory structure:
   ```
   src/
   └── app/
       ├── __init__.py
       ├── core/
       │   └── __init__.py
       ├── models/
       │   └── __init__.py
       ├── schemas/
       │   └── __init__.py
       └── api/
           └── __init__.py
   tests/
   └── __init__.py
   ```
   All __init__.py files empty for now.

3. Configure Ruff in pyproject.toml:
   - target-version = "py313"
   - line-length = 99
   - select = ["E", "F", "I", "N", "UP", "B", "A", "SIM", "TCH"]
   - src = ["src"]

4. Configure mypy in pyproject.toml:
   - python_version = "3.13"
   - strict = true
   - plugins = ["pydantic.mypy"]

5. Configure pytest in pyproject.toml:
   - asyncio_mode = "auto"
   - testpaths = ["tests"]

6. Create .github/workflows/ci.yml:
   - Trigger on push and pull_request
   - PostgreSQL 16 service container
   - Steps: checkout, setup-uv, uv sync, ruff check, ruff format --check, mypy src/, pytest
   - Use DATABASE_URL env var for test DB

7. Run `uv sync` to generate uv.lock.

8. Add uv.lock to git. Add `.venv/` to .gitignore.
  </action>
  <verify>
uv sync succeeds without errors.
uv run ruff check src/ exits 0.
uv run python -c "import app; print('ok')" prints "ok" (with PYTHONPATH=src).
ls src/app/core/__init__.py exists.
cat .github/workflows/ci.yml shows CI config.
  </verify>
  <done>New project initialized with uv, all dependencies installed, ruff/mypy/pytest configured, CI workflow created.</done>
</task>
