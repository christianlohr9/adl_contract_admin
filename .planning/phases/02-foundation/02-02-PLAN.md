**Tech stack from research:**
- FastAPI with lifespan (not deprecated on_event)
- SQLAlchemy 2.0 async: AsyncAttrs DeclarativeBase, create_async_engine, async_sessionmaker
- asyncpg driver
- Pydantic v2 settings with @lru_cache
- expire_on_commit=False (critical for async)
- uvicorn ASGI server

**Architecture patterns (from 02-RESEARCH.md):**
- Pattern 1: Async Engine + Session Factory (module-level singletons)
- Pattern 2: AsyncAttrs DeclarativeBase
- Pattern 3: Pydantic v2 Settings with @lru_cache
- Pattern 4: FastAPI Lifespan context manager

**Anti-patterns to avoid:**
- @app.on_event("startup") — deprecated, use lifespan
- expire_on_commit=True — causes MissingGreenlet in async
- Creating engine per-request — create once at module level
- Base.metadata.create_all() in production — use Alembic

**From CONTEXT.md:**
- Docker Compose is the ONLY way to run/test
- Fully async from day one
- No business logic, no domain routes — just health check
