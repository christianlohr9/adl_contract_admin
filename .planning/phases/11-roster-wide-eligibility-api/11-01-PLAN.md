  <files>src/app/services/roster_eligibility.py</files>
  <action>
Create `get_roster_eligibility()` service that aggregates per-player contract tools across an entire team roster.

**Function signature:**
```python
async def get_roster_eligibility(
    session: AsyncSession,
    team_id: int,
    season: int,
) -> RosterEligibilitySummary:
```

**Logic flow:**
1. Call `get_all_window_statuses(session, season)` to determine which action windows are open
2. Filter to only actions with status == "open"
3. Load team roster: query RosterEntry where team_id + season, joinedload Player and Contract (same pattern as `teams.py:get_team_roster`)
4. For each open action, iterate roster players:
   - Call `check_eligibility(session, player_id, season, action)` — skip if not eligible
   - For eligible players, call the relevant calculate service and extract the headline value
   - Wrap each eligible player into a `PlayerActionSummary` dataclass
5. Group results into `ActionGroup` dataclasses (one per open action with eligible players)
6. Return `RosterEligibilitySummary` with action_groups and window_statuses

**Dataclasses to define in this file:**
- `PlayerActionSummary`: player_id, player_name, position, current_salary (Decimal|None), headline_value (Decimal|None), headline_label (str)
- `ActionGroup`: action (str), window_closes (date|None), players (list[PlayerActionSummary])
- `RosterEligibilitySummary`: team_id (int), season (int), action_groups (list[ActionGroup]), window_statuses (dict[str, WindowStatus])

**Headline value extraction per action (wrap each in try/except, log errors, skip player on failure):**
- `extension`: call `calculate_extensions()` → first option's `total_value`, label "Extension Value"
- `franchise_tag`: call `calculate_franchise_tags()` → first option's `salary`, label "Tag Salary"
- `erfa_tender`: call `calculate_tenders()` → `erfa_option.salary`, label "ERFA Tender"
- `rfa_tender`: call `calculate_tenders()` → first `rfa_options` salary, label "RFA Tender"
- `buyout_restructure`: call `calculate_buyout()` → `opening_bid`, label "Opening Bid"
- `fifth_year_option`: call `calculate_5yo()` → `salary`, label "5YO Salary"
- `proven_performance_escalator`: call `calculate_ppe()` → `escalator_salary`, label "PPE Salary"

**Important:**
- Use per-player error isolation (try/except per calculate call) — one player failing doesn't skip the whole action group
- Sort players within each group by headline_value descending (highest value first, None last)
- Only include action groups that have at least 1 eligible player
- For tenders: a player might be ERFA-eligible, RFA-eligible, or both — check each independently since they're separate action types in the eligibility system
- Don't duplicate the roster query — load once, reuse for all actions
