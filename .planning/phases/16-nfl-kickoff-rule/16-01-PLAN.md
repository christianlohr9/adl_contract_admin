<task type="auto">
  <name>Task 1: Add NFL kickoff eligibility check to extensions.py</name>
  <files>src/app/services/extensions.py</files>
  <action>
Insert kickoff gate into `check_extension_eligibility()` after the rookie/UDFA max-years check (line ~186) and before the EXT cooldown check (line ~188).

Logic:
- Only applies when `is_rookie_contract or is_udfa_contract` AND `contract.years_remaining <= 1` (final year)
- Query SeasonCalendar for the current season's `regular_season_start`
- If `regular_season_start` is set and `date.today() < regular_season_start`: return `(False, f"Rookie/UDFA extension unavailable until NFL kickoff ({calendar.regular_season_start.strftime('%b %d, %Y')})")`
- If `regular_season_start` is NULL: return `(False, "Rookie/UDFA extension requires NFL season start date (not yet configured in league calendar)")`
- If today >= regular_season_start: pass through (eligible, continue other checks)

Reuse the existing calendar query pattern from window_status.py (`select(SeasonCalendar).where(SeasonCalendar.season == season)`).

Add `from datetime import date` and `from app.models.season_calendar import SeasonCalendar` imports.

IMPORTANT: The kickoff check MUST be inside the existing `if is_rookie_contract or is_udfa_contract:` block. Do NOT apply it to all extensions — only rookie/UDFA contracts. And only when in final year (years_remaining <= 1). See RESEARCH.md Pitfall 1 and Pitfall 2.

IMPORTANT: Keep the check AFTER the max-years check (a player on a short rookie deal is already ineligible — no need to also check kickoff). Place it as the last check inside the rookie/UDFA block before falling through to the general checks.
  </action>

  <done>check_extension_eligibility() returns kickoff-related ineligibility reason for final-year rookie/UDFA contracts when today < regular_season_start. Non-rookie contracts are unaffected.</done>
