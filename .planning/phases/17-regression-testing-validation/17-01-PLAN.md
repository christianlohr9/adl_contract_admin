<task type="auto">
  <name>Task 1: Create CLI validation script</name>
  <files>scripts/validate_eligibility.py</files>
  <action>
Create a standalone async Python script that:

1. **Connects directly to the database** using `async_session` from `app.core.db` — NOT via HTTP API. This avoids needing a running server and is faster.

2. **Loads all players with contracts** for season 2026:
   - Query all distinct player_ids from Contract table where season=2026
   - Load each Player record for name/position/draft info

3. **Runs all 7 eligibility checks per player** via `check_eligibility()` from `app.services.eligibility`:
   - extension, franchise_tag, erfa_tender, rfa_tender, buyout_restructure, fifth_year_option, proven_performance_escalator

4. **Applies anomaly detection rules** (same as Phase 15 validation):
   - Extension eligible but years_remaining >= 2
   - Tag eligible but years_remaining > 0
   - ERFA eligible but salary above veteran minimum
   - 5YO eligible but not draft round 1
   - PPE eligible but not draft rounds 2-5
   - PPE eligible but position is PK or PN
   - Any error/exception during check

5. **Outputs a structured report** with:
   - Summary table: total players, total checks, anomalies, errors
   - Per-action breakdown: eligible count, ineligible count, error count
   - Anomaly details section (if any): player name, action, reason, contract details
   - Notes on expected counts (e.g., extension window status)

6. **CLI interface:** `uv run python scripts/validate_eligibility.py [--season 2026] [--output FILE]`
   - Default season: 2026
   - Default output: stdout (markdown format)
   - Optional `--output` writes to file

Use `asyncio.run()` as entry point. Import `async_session` from `app.core.db`. Use `argparse` for CLI args. Print progress to stderr (team count, player count) so stdout stays clean for piping.

Do NOT add this to the test suite or conftest — it's a standalone script per CONTEXT.md.
