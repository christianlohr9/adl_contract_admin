Create `src/app/services/rules.py` with:

1. **Rules loader functions** using `@lru_cache` for file-based caching:
   - `load_constants(name: str) -> dict` — loads `rules/constants/{name}.json`
   - `load_formulas(name: str) -> dict` — loads `rules/formulas/{name}.yaml`
   - Convenience wrappers:
     - `get_contract_constants() -> dict` — loads contracts.json
     - `get_salary_cap_constants() -> dict` — loads salary_cap.json
     - `get_league_constants() -> dict` — loads league.json

   Path resolution: Use `Path(__file__).resolve().parent.parent.parent.parent / "rules"` to find the rules directory relative to the service file (services/ → app/ → src/ → project root).

2. **Salary rounding helpers** (all operate on `Decimal`, return `Decimal`):
   - `round_to_10k(amount: Decimal) -> Decimal` — round to nearest $10k using ROUND_HALF_UP
   - `round_to_100k(amount: Decimal) -> Decimal` — round to nearest $100k using ROUND_HALF_UP
   - `floor_100k(amount: Decimal) -> Decimal` — floor to $100k
   - `ceil_100k(amount: Decimal) -> Decimal` — ceil to $100k
   - `round_to_nearest_4(value: int) -> int` — round to nearest multiple of 4 (for PR Starter Floor)

   Implementation detail for round_to_10k: `(amount / 10_000).quantize(Decimal("1"), rounding=ROUND_HALF_UP) * 10_000`. But since salaries are stored in millions (e.g. 10.07 = $10.07M), the rounding should work in millions: `round_to_10k` rounds to nearest 0.01 in millions (which is $10k). So: `amount.quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)`. Similarly `round_to_100k` rounds to nearest 0.1 in millions. Verify against the Contract model which stores salary as Numeric(5,2) in millions.

3. **Helper to get season-specific values:**
   - `get_veteran_minimum(season: int) -> Decimal` — from contracts.json veteran_minimum_by_year
   - `get_rookie_minimum(season: int) -> Decimal` — from contracts.json rookie_minimum_by_year
   - `get_sd_minimum(season: int) -> Decimal` — from contracts.json sd_minimum_by_year
   - `get_salary_growth_rate() -> Decimal` — returns Decimal("0.10") from contracts.json

   For season lookups, fall back to the latest available year if the requested year isn't in the dict.

All values should be `Decimal` throughout — convert from JSON float/int at load time in the convenience functions. Do NOT use float arithmetic anywhere in this module.

  <name>Task 2: Create EPV calculation core</name>
  <files>src/app/services/epv.py</files>
  <action>
Create `src/app/services/epv.py` with the core EPV calculation functions. This module is an internal helper called by extensions, tags, and other tools — not exposed as a standalone API.

1. **Result dataclass:**
```python
@dataclass
class EPVResult:
    epv_curr: Decimal | None   # Current non-robust season EPV (None if offseason)
    epv_new: Decimal | None    # Most recent robust season EPV
    epv_old: Decimal | None    # Previous robust season EPV
    pr_curr: int | None        # Current non-robust PR
    pr_new: int | None         # Most recent robust PR
    pr_old: int | None         # Previous robust PR
    floor: Decimal             # 75% or 82.5% of previous salary
    position: str
    seasons_used: list[int]    # Which seasons contributed to EPV
```

2. **Position rank calculation:**
   - `async def get_position_rank(session: AsyncSession, player_id: int, position: str, season: int) -> int | None`
   - Calculate the player's position rank for a season using PlayerScore data
   - Get total points (week="YTD") for all players at the same position in that season
   - Rank by points descending (dense_rank)
   - Return the player's rank, or None if no scores
   - A "robust" season requires the player to have ≥8 active weeks (COUNT of PlayerScore records where week is numeric and season matches). Use the `ext_robust_games_minimum` from contracts.json (value: 8).
   - `async def is_robust_season(session: AsyncSession, player_id: int, season: int) -> bool`

3. **Performance salary (EPV at a rank):**
   - `async def calculate_performance_salary(session: AsyncSession, position: str, pr: int, season: int) -> Decimal`
   - Formula from extensions.yaml: `ROUND_TO_10K(AVERAGE(SAL(2*PR - 3), SAL(2*PR - 2)))`
   - SAL(n) = nth highest salary at position from Contract table for that season
   - For PR=1: formula becomes `2*AVG(SAL(1),SAL(2)) - AVG(SAL(3),SAL(4))` (linear extrapolation)
   - Floor PR at PR Starter Floor (from extensions.yaml formula, but for now use a reasonable default or pass it in)
   - Query Contract table: `SELECT salary FROM contracts WHERE season=X JOIN players WHERE position=Y ORDER BY salary DESC OFFSET (n-1) LIMIT 1`
   - Convert salary from float to Decimal immediately: `Decimal(str(salary))`

4. **EPV calculation orchestrator:**
   - `async def calculate_epv(session: AsyncSession, player_id: int, season: int, previous_salary: Decimal, years_remaining: int) -> EPVResult`
   - Determine which seasons to use for EPV_curr, EPV_new, EPV_old:
     - Look back up to 3 seasons for robust PRs
     - EPV_new = most recent robust season's performance salary
     - EPV_old = second most recent robust season's performance salary (floor at PR Starter Floor)
     - EPV_curr = current season performance salary if season has started but PR is not yet robust (set to None for offseason calculations)
   - Floor = 75% of previous salary if years_remaining > 0, 82.5% if years_remaining == 0 (expired contract)
   - Use `get_contract_constants()` for the floor percentages: `ext_prev_sal_floor_active_pct` (0.75) and `ext_prev_sal_floor_expired_pct` (0.825)

Important: All salary math uses Decimal. Convert from DB float to Decimal at the boundary (when reading from query results). Use `round_to_10k` from rules.py for final EPV values.

Do NOT use Polars/Pandas. Use SQLAlchemy async queries.
