```python
@dataclass
class TagOption:
    tag_type: str              # "EFT", "NEFT", "TT"
    salary: Decimal            # Calculated tag salary
    opening_bid: Decimal | None  # Auction opening bid (NEFT/TT only, None for EFT)
    contract_years: int        # Always 1 for tags
    guarantee_level: str       # Always "FG"
    compensation: str          # "None" for EFT/TT, "Two 1st round picks" for NEFT

@dataclass
class FranchiseTagResult:
    player_id: int
    player_name: str
    position: str
    previous_salary: Decimal
    options: list[TagOption]    # Up to 3 (EFT, NEFT, TT)
    eligible: bool
    ineligibility_reason: str | None
    consecutive_tag_count: int  # How many consecutive EFT/NEFT tags
```

2. **Tag salary calculation:**
   - `async def calculate_tag_salary(session: AsyncSession, position: str, tag_type: str, prev_salary: Decimal, season: int) -> Decimal`
   - From free_agency.yaml:
     - EFT/NEFT: `MAX(ADL_Cap_Pct × AVG(Top5_Salaries_at_Position_EOY), 1.20 × prev_salary)`, rounded to nearest $10k
     - TT: `MAX(ADL_Cap_Pct × AVG(Top10_Salaries_at_Position_EOY), 1.20 × prev_salary)`, rounded to nearest $10k
   - ADL_Cap_Pct: The salary cap formula multiplier (0.81 from salary_cap.json `salary_cap_formula_multiplier`) — NOTE: This value represents the relationship between NFL and ADL caps. For tag calculations, it's the percentage of the positional salary average. Per bylaws, this is simply the average of top-N salaries — the Cap% reference may be a legacy formula detail. Implement as: `AVG(Top_N_Salaries)` and `1.20 × prev_salary`, take the MAX.
   - Query for top-N salaries: `SELECT salary FROM contracts WHERE season=(season-1) JOIN players WHERE position=pos ORDER BY salary DESC LIMIT N` — then average those N values
   - Convert each salary to Decimal before averaging

3. **Opening bid calculation (NEFT and TT only):**
   - `def calculate_opening_bid(tag_salary: Decimal, sd_minimum: Decimal) -> Decimal`
   - From free_agency.yaml: `MAX(CEIL_100K(SD_Min - 0.1), FLOOR_100K(tag_salary))`
   - Use `ceil_100k` and `floor_100k` from rules.py

4. **Consecutive tag check:**
   - `async def get_consecutive_tag_count(session: AsyncSession, player_id: int, season: int) -> int`
   - Check previous seasons' contracts for EFT/NEFT designations
   - Max 3 consecutive EFT/NEFT tags per contracts.json `max_consecutive_neft_eft_tags`
   - Third consecutive tag salary: `MAX(1.44 × prev_tag_salary, 1.20 × positional_FT_price, highest_positional_FT_amount)`

5. **Eligibility check:**
   - `async def check_tag_eligibility(session: AsyncSession, player_id: int, season: int) -> tuple[bool, str | None]`
   - Player must have 0 remaining contract years (expired contract)
   - Check consecutive tag limit (max 3 for EFT/NEFT combined)

6. **Main orchestrator:**
   - `async def calculate_franchise_tags(session: AsyncSession, player_id: int, season: int) -> FranchiseTagResult`
   - Load player + previous contract
   - Check eligibility
   - Calculate all three tag options (EFT, NEFT, TT)
   - Apply consecutive tag premium if applicable
   - Return FranchiseTagResult with all options

All arithmetic in Decimal. Convert DB floats at boundary.

Create `src/app/services/tenders.py` with:

1. **Result dataclasses:**
```python
@dataclass
class TenderOption:
    tender_type: str           # "ERFA", "FRFA", "SRFA", "ORFA", "RRFA"
    salary: Decimal            # Calculated tender salary / opening bid
    contract_years: int        # 1 for ERFA, 1 default for RFA
    compensation: str          # Draft pick compensation description

@dataclass
class TenderResult:
    player_id: int
    player_name: str
    position: str
    previous_salary: Decimal
    erfa_option: TenderOption | None    # ERFA if eligible
    rfa_options: list[TenderOption]     # FRFA, SRFA, ORFA, RRFA if eligible
    erfa_eligible: bool
    rfa_eligible: bool
    ineligibility_reasons: list[str]
```

2. **ERFA tender calculation:**
   - `def calculate_erfa_salary(prev_salary: Decimal, season: int) -> Decimal`
   - From free_agency.yaml: `MAX(veteran_minimum, 1.10 × prev_salary)`
   - Use `get_veteran_minimum(season)` from rules.py
   - Contract is always 1 year

3. **ERFA eligibility:**
   - `async def check_erfa_eligibility(session: AsyncSession, player_id: int, season: int) -> tuple[bool, str | None]`
   - Player's expired contract must have been signed at or below the veteran minimum in one of the previous two league years
   - Player's expired contract must NOT be an ERFA contract itself
   - Player must have 0 years remaining

4. **RFA tender calculations:**
   - `def calculate_frfa_bid(prev_salary: Decimal) -> Decimal` — `FLOOR_100K(MAX(NFL_FRFA_price, 2.20 × prev_salary))`
   - `def calculate_srfa_bid(prev_salary: Decimal) -> Decimal` — `FLOOR_100K(MAX(NFL_SRFA_price, 1.65 × prev_salary))`
   - `def calculate_orfa_bid(prev_salary: Decimal) -> Decimal` — `FLOOR_100K(MAX(NFL_ORFA_price, 1.10 × prev_salary))`
   - `def calculate_rrfa_bid() -> Decimal` — `FLOOR_100K(NFL_RRFA_price)`
   - NFL RFA prices are external values not in our constants — for now, accept them as parameters or use placeholder values with a TODO noting they need to be added to constants. The multiplier values (2.20, 1.65, 1.10) come from contracts.json `rfa_tenders`.
   - Use `floor_100k` from rules.py for rounding

5. **RFA eligibility:**
   - `async def check_rfa_eligibility(session: AsyncSession, player_id: int, season: int) -> tuple[bool, str | None]`
   - From free_agency.yaml rfa_eligibility:
     - Contract must not be 4+ years old
     - Contract must not include ineligible types from 2021 or earlier: EFT, NEFT, TT, NEFToff, TToff, FRFA, SRFA, ORFA, RRFA, B/R, EXT, 5YO
     - Must not be multi-year UFA from 2023 or earlier
   - Check designation field on the player's most recent contract

6. **Main orchestrator:**
   - `async def calculate_tenders(session: AsyncSession, player_id: int, season: int) -> TenderResult`
   - Load player + previous contract
   - Check ERFA eligibility → if eligible, calculate ERFA salary
   - Check RFA eligibility → if eligible, calculate all 4 RFA tender options
   - Return TenderResult

All arithmetic in Decimal.
