  <name>Task 1: Implement EYS calculation and salary smoothing</name>
  <files>src/app/services/extensions.py</files>
  <action>
Create `src/app/services/extensions.py` with:

1. **Result dataclasses:**
```python
@dataclass
class ExtensionOption:
    extension_years: int          # Number of years being added
    eys: Decimal                  # Extension Year Salary
    smoothed_salary: Decimal      # Final annual salary after smoothing
    total_value: Decimal          # Total contract value across all years
    contract_type: str            # Always "SD" for extensions
    years_remaining_after: int    # Total years on new contract

@dataclass
class ExtensionResult:
    player_id: int
    player_name: str
    position: str
    current_salary: Decimal
    current_years_remaining: int
    epv_details: EPVResult        # Full EPV breakdown
    options: list[ExtensionOption] # All valid extension options
    eligible: bool                # Whether player is eligible
    ineligibility_reason: str | None  # Why ineligible (if applicable)
```

2. **EYS calculation function:**
   - `def calculate_eys(epv: EPVResult, extension_years: int, has_5yo: bool = False) -> Decimal`
   - Formula from extensions.yaml: `MAX(EPV_curr, EPV_new, EPV_old, floor) × (1.15 - 0.05 × EXT_years)`
   - Collect non-None EPV values + floor into candidates list
   - Take max of candidates
   - 5YO adjustment: `effective_years = extension_years - 1` if has_5yo
   - Multiplier: `Decimal("1.15") - Decimal("0.05") * effective_years`
   - Return `round_to_10k(max_epv * multiplier)` from rules.py

3. **Salary smoothing function:**
   - `def calculate_smoothed_salary(current_salary: Decimal, eys: Decimal, prev_years: int, ext_years: int) -> Decimal`
   - Formula from extensions.yaml ext_salary_smoothing:
     - Growth rate: `Decimal("1.10")` (from contracts.json salary_growth_rate)
     - Past total: `sum(current_salary * growth^i for i in range(prev_years))`
     - Future total: `sum(eys * growth^i for i in range(prev_years, prev_years + ext_years))`
     - Denominator: `sum(growth^i for i in range(prev_years + ext_years))`
     - Smoothed = `round_to_10k((past_total + future_total) / denominator)`
   - Use `get_salary_growth_rate()` from rules.py for the growth constant

4. **SD minimum floor:**
   - After smoothing, if smoothed_salary < SD minimum for the season, round up to SD minimum
   - Per extensions.yaml: "Final EXT salaries below the minimum SD salary are rounded up to the minimum SD salary"
   - Use `get_sd_minimum(season)` from rules.py

All arithmetic in Decimal. No floats.

<task type="auto">
  <name>Task 2: Build extension options service with eligibility checks</name>
  <files>src/app/services/extensions.py</files>
  <action>
Add to `src/app/services/extensions.py`:

1. **Eligibility checker:**
   - `async def check_extension_eligibility(session: AsyncSession, player_id: int, season: int) -> tuple[bool, str | None]`
   - Check all rules from extensions.yaml ext_additional_rules:
     - Player must have years_remaining <= 1 on current contract (">= 2 are ineligible")
     - Player cannot have received an EXT in the current or prior window (check designation for "EXT" in recent contracts)
     - Player must have at least one robust PR (check via `is_robust_season` from epv.py for recent seasons)
     - EXT cannot cause total years to exceed 6 (max_contract_years from contracts.json)
     - Players on rookie contracts signed for less than max years are ineligible
   - Return `(True, None)` if eligible, `(False, "reason string")` if not

2. **Extension options calculator:**
   - `async def calculate_extensions(session: AsyncSession, player_id: int, season: int) -> ExtensionResult`
   - Steps:
     a. Load player + current active contract from DB
     b. Check eligibility — if ineligible, return ExtensionResult with eligible=False and reason
     c. Calculate EPV using `calculate_epv()` from epv.py
     d. Determine 5YO status from contract designation (contains "+" or "5YO")
     e. For each valid extension length (1 to max where total ≤ 6 years):
        - Calculate EYS for that extension length
        - Calculate smoothed salary
        - Apply SD minimum floor
        - Calculate total contract value (smoothed_salary × total_years, but with growth applied)
        - Create ExtensionOption
     f. Return ExtensionResult with all options

   - Convert contract salary from float to Decimal at the boundary: `Decimal(str(contract.salary))`
   - All extensions produce SD contract type per bylaws: "All EXTs are SD (Standard) contracts"

3. **Determine max extension years:**
   - Current years_remaining + extension_years ≤ 6 (max_contract_years)
   - For expired contracts (years_remaining=0): max extension is 6
   - For 1 year remaining: max extension is 5
   - Minimum extension is 1 year

Query patterns:
- Get current contract: `SELECT * FROM contracts WHERE player_id=X AND season=Y AND status='active' ORDER BY salary DESC LIMIT 1`
- Get player: `SELECT * FROM players WHERE id=X`
