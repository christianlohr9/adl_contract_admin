1. **Result dataclasses:**
```python
@dataclass
class BuyoutOption:
    action: str                  # "retain_restructure", "retain_revert", "revert_transfer", "buyout_transfer"
    description: str             # Human-readable description
    salary: Decimal | None       # New salary (None for revert options)
    contract_years: int | None   # New years (None for revert)

@dataclass
class BuyoutSalaryTier:
    contract_years: int          # Years declared in bid
    salary: Decimal              # Calculated salary at that year count

@dataclass
class BuyoutResult:
    player_id: int
    player_name: str
    position: str
    current_salary: Decimal
    current_years: int
    opening_bid: Decimal         # SD minimum rounded up to $100k
    salary_tiers: list[BuyoutSalaryTier]  # Salary at each contract year option
    gm_options: list[BuyoutOption]        # All 4 GM options
    eligible: bool
    ineligibility_reason: str | None
```

2. **B/R salary calculation:**
   - `def calculate_br_salary(high_bid: Decimal, contract_years: int, sd_minimum: Decimal) -> Decimal`
   - From free_agency.yaml: `high_bid × (1 - 0.05 × (contract_years - 1))`
   - Discount per year beyond 1: 0.05 (from contracts.json `buyout_restructure.salary_discount_per_year_beyond_1`)
   - Floor at SD minimum: salary may not drop below SD minimum
   - Return `round_to_10k(max(calculated, sd_minimum))`

3. **Opening bid:**
   - From contract_tools.yaml: SD minimum rounded up to nearest $100k
   - Use `ceil_100k(get_sd_minimum(season))` from rules.py

4. **Salary tier table:**
   - `def calculate_br_salary_tiers(opening_bid: Decimal, sd_minimum: Decimal, max_years: int = 6) -> list[BuyoutSalaryTier]`
   - Calculate salary at each year option (1 through max_years) using the opening bid as high_bid
   - This shows the GM what salary would be at each contract length

5. **GM options:**
   - Build all 4 options from contract_tools.yaml buyout_restructure_rules:
     - retain_restructure: Re-sign at new salary structure
     - retain_revert: Revert to exact pre-B/R contract
     - revert_transfer: Revert and send to high bidder
     - buyout_transfer: Release to high bidder at new salary

6. **Eligibility:**
   - `async def check_buyout_eligibility(session: AsyncSession, player_id: int, season: int) -> tuple[bool, str | None]`
   - Any player with a contract is eligible EXCEPT:
     - Players on Drafted Rookie or UDFA contracts are ineligible until the final year (including 5th year if 5YO exercised)
   - Check designation field for "R/F" or "UDFA" and years_remaining

7. **Main orchestrator:**
   - `async def calculate_buyout(session: AsyncSession, player_id: int, season: int) -> BuyoutResult`
   - Load player + current contract
   - Check eligibility
   - Calculate opening bid and salary tiers
   - Build GM options
   - Return BuyoutResult

All arithmetic in Decimal.

```python
class FifthYearOptionResult:
```

2. **5YO salary calculation:**
   - `async def calculate_5yo(session: AsyncSession, player_id: int, season: int) -> FifthYearOptionResult`
   - From extensions.yaml fifth_year_option and contract_tools.yaml:
     - Eligible: first-round drafted rookies only, in their 4th season
     - Determine percentile tier based on ADL-wide Total Starter Points relative to PR Starter Floor:
       - Top 87.5%: salary = NEFT price (use `calculate_tag_salary` with tag_type="NEFT" from franchise_tags.py)
       - 75-87.5%: salary = TT price (use `calculate_tag_salary` with tag_type="TT")
       - 25-75%: salary = TT price but using 3rd-20th highest salaries instead of 1st-10th
       - Bottom 25%: salary = TT price but using 3rd-25th highest salaries instead of 1st-10th
     - For the modified TT calculations (25-75% and bottom 25%), create a helper:
       `async def calculate_modified_tt_salary(session, position, prev_salary, season, start_rank, end_rank) -> Decimal`
       Same formula as TT but averaging salaries from rank `start_rank` to `end_rank` instead of top 10
   - Eligibility: Check `player.draft_round == 1` and contract is in year 4

3. **Percentile calculation:**
   - `async def calculate_starter_percentile(session: AsyncSession, player_id: int, position: str, season: int) -> float | None`
   - Get total points for all players at position who scored above PR Starter Floor
   - Rank the target player within that group
   - Return percentile (0.0 to 1.0)
   - PR Starter Floor is from extensions.yaml — for now, this needs to be computed or passed in. Use a reasonable approach: count starters and determine floor based on league structure.

**Proven Performance Escalator (PPE):**

```python
@dataclass
class PPEResult:
    player_id: int
    player_name: str
    position: str
    current_salary: Decimal
    escalator_salary: Decimal | None  # None if not eligible or current salary is higher
    escalator_level: str | None       # "level_3" or "level_1_2"
    eligible: bool
    ineligibility_reason: str | None
```

5. **PPE calculation:**
   - `async def calculate_ppe(session: AsyncSession, player_id: int, season: int) -> PPEResult`
   - From extensions.yaml proven_performance_escalator and contract_tools.yaml:
     - Eligible: rounds 2-6 drafted rookies (from contracts.json `proven_performance_escalator.eligible_rounds: [2,3,4,5]`) in year 4 of rookie contract
     - Ineligible positions: PK, PN (from contracts.json)
     - Level 3 (75th+ percentile): salary = SRFA tag price (from tenders.py `calculate_srfa_bid`)
     - Level 1-2 (0-75th percentile): salary = ORFA tag price (from tenders.py `calculate_orfa_bid`)
     - If current salary > escalator salary, player keeps current salary
   - Uses same `calculate_starter_percentile` helper as 5YO

All arithmetic in Decimal. Reuse franchise_tags.py and tenders.py for tag/tender price lookups.
