Create `contract_classifier.py` with a `classify_contract_type(salary, designation, signed_season, season, draft_round)` function that returns `ContractType` (NG, SD, or FG).

Classification rules from bylaws (contracts.json `contract_types`):
- **FG** (Fully Guaranteed): 1st round drafted rookies, players with exercised 5YO (designation contains "+" or "5YO"), franchise-tagged players (designation contains "EFT", "NEFT", "TT")
- **SD** (Standard): 2nd+ round drafted rookies at or above SD minimum, AND all other players at or above the SD minimum for the season
- **NG** (Non-Guaranteed): Players below the SD minimum salary, OR unsigned drafted rookies

Use `get_sd_minimum(season)` from `rules.py` to get the SD threshold for comparison.

For designation parsing:
- Draft round detection: look for patterns like "2021 1.02" (round 1), "2021 2.15" (round 2) — the digit before the "." is the round
- 5YO detection: "+" in designation or "5YO" in designation (already used in extensions.py)
- Tag detection: "EFT" or "NEFT" or "TT" appearing in designation (not as substring of other words — e.g. "NEFT" not "NEFToff")
- EXT contracts: always SD per bylaws ("All EXTs are SD contracts")

Then update `roster_sync.py` to call `classify_contract_type()` instead of hardcoding `ContractType.NG`. Pass the parsed salary, designation, signed_season, current season, and draft round (extract from designation if available, else None).

The classifier should be a pure function (no DB access) — all inputs are passed as parameters.

<task type="auto">
  <name>Task 2: Cap penalty calculator service</name>
  <files>src/app/services/cap_penalties.py</files>
  <action>
Create `cap_penalties.py` with Decimal-only salary math (convert floats at boundary, use round_to_10k from rules.py for all penalty rounding per `cap_penalty_rounding` in salary_cap.json).

Implement these functions:

**`calculate_ng_penalty(salary, years_remaining) -> PenaltyResult`**
- Always returns 0 for both year_1 and additional_years (no penalty regardless of years)

**`calculate_sd_penalty(salary, years_remaining) -> PenaltyResult`**
- year_1_penalty = round_to_10k(0.60 × salary)
- additional_years_penalty = round_to_10k(0.30 × salary × (years_remaining - 1))
- If years_remaining <= 1, additional_years_penalty = 0

**`calculate_fg_penalty(salary, years_remaining) -> PenaltyResult`**
- total = sum of (salary × 1.1^n) for n in range(years_remaining)
- Round total to 10k
- If years_remaining > 1: year_1 = ceil_100k(total / 2), year_2 = floor_100k(total / 2) per bylaws multi-year split
- If years_remaining == 1: year_1 = total, year_2 = 0

**`calculate_penalty(contract_type, salary, years_remaining, ...) -> PenaltyResult`**
- Dispatcher that calls the appropriate calculator
- Additional kwargs: `is_suspended=False`, `is_retired=False`, `is_deceased=False`, `pre_july_1=True`
- Suspended: multiply total by 0.50 (per `suspended_player_penalty_discount`)
- Retired/deceased: penalty = 0
- Acceleration: if `pre_july_1=True`, total penalty is lump sum in year 1 (year_1 = year_1 + additional_years, additional_years = 0)
- If `pre_july_1=False`: standard split (year_1 stays, additional_years assessed next year)

**Result dataclass `PenaltyResult`:**
- contract_type: str
- salary: Decimal
- years_remaining: int
- year_1_penalty: Decimal (current year cap hit)
- additional_years_penalty: Decimal (next offseason cap hit)
- total_penalty: Decimal
- notes: str (explanation of calculation — e.g. "SD penalty: 60% year-1 + 30% × 3 additional years")

Use `get_cap_penalty_rates()` helper — add to `rules.py` to load from `salary_cap.json["cap_penalty_rates"]` with `@lru_cache`.

Do NOT use ceil_100k/floor_100k for SD/NG penalties — only for FG multi-year split per bylaws. Use round_to_10k for all other rounding.
