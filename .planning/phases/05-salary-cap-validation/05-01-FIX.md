Fix both regex patterns:

1. **UAT-001 (Major): Tag regex** — Update `_TAG_RE` to match tag variants with optional suffixes:
   - `EFT`, `EFT1`, `EFT2` (consecutive tag numbers)
   - `NEFT`, `NEFT1`, `NEFToff` (offer sheet signed)
   - `TT`, `TT1`, `TToff` (offer sheet signed)
   - New pattern: `r"\b(EFT|NEFT|TT)(\d+|off)?\b"` — matches base tag with optional digit(s) or "off" suffix

2. **UAT-002 (Minor): EXT regex** — Update `_EXT_RE` to match extension variants:
   - `EXT` (plain extension)
   - `iEXT` (in-season extension)
   - `oEXT` (offseason extension)
   - New pattern: `r"\b[io]?EXT\b"` — matches optional i/o prefix before EXT

Update the inline comments to reflect the new patterns.
  </action>
