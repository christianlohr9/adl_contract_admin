<task type="auto">
  <name>Task 1: Create sync orchestrator and APScheduler integration</name>
  <files>pyproject.toml, uv.lock, src/app/services/sync_orchestrator.py, src/app/main.py, src/app/core/config.py</files>
  <action>
1. Install APScheduler: `uv add apscheduler`
2. Add scheduler settings to config.py:
   - `sync_interval_hours: int = 6` (how often to auto-sync)
   - `sync_enabled: bool = True` (toggle background sync)
   - `sync_historical_years: list[int] = [2020, 2021, 2022, 2023, 2024, 2025]` (years to sync scores for)
3. Create `src/app/services/sync_orchestrator.py` with:
   - `SyncStatus` dataclass: `last_sync: datetime | None`, `in_progress: bool`, `last_result: dict | None`, `last_error: str | None`
   - Module-level `_sync_status = SyncStatus(...)` — simple in-memory state tracking
   - `def get_sync_status() -> SyncStatus` — returns current status
   - `async def run_full_sync(settings: Settings) -> dict`:
     - Set in_progress=True, clear last_error
     - Create MFLClient from settings
     - Acquire async session from async_session factory
     - Execute sync in order within a single transaction:
       1. `sync_teams(client, session)` — must run first (teams referenced by rosters)
       2. `sync_players(client, session)` — must run before rosters (players referenced by roster entries)
       3. `sync_rosters(client, session, season=settings.mfl_year)` — depends on teams + players
       4. `sync_scores(client, session, season=settings.mfl_year)` — current season YTD
     - `await session.commit()` — single transaction for atomicity
     - Update _sync_status with results and timestamp
     - On any exception: rollback, set last_error, log error, re-raise
     - Set in_progress=False in finally block
     - Return dict of {service_name: SyncResult} for each step
   - `async def run_historical_sync(settings: Settings) -> dict[int, SyncResult]`:
     - Separate function for historical score sync (long-running)
     - For each year in sync_historical_years:
       - Create year-scoped MFLClient
       - Sync YTD scores for that year
     - This does NOT sync rosters/teams for past years — just scores
4. Update `src/app/main.py` lifespan:
   - If `settings.sync_enabled`:
     - Create `AsyncScheduler()`
     - Add schedule: `run_full_sync` with `IntervalTrigger(hours=settings.sync_interval_hours)`
     - `await scheduler.start_in_background()`
   - Yield (with scheduler in scope so it stays alive)
   - Cleanup: scheduler context manager handles shutdown

Import APScheduler as: `from apscheduler import AsyncScheduler` and `from apscheduler.triggers.interval import IntervalTrigger`

Do NOT run sync on startup — only on schedule. The manual trigger endpoint (Task 2) handles on-demand sync.

Wrap the entire sync in try/except so a failed sync never crashes the scheduler or the app. Log the error and set last_error status.

<task type="auto">
  <name>Task 2: Create sync API endpoint with status reporting</name>
  <files>src/app/api/sync.py, src/app/api/__init__.py, src/app/main.py, src/app/schemas/sync.py, src/app/schemas/__init__.py</files>
  <action>
1. Create `src/app/schemas/sync.py` with Pydantic response models:
   - `SyncResultSchema`: `created: int`, `updated: int`, `errors: list[str]`
   - `SyncStatusSchema`: `last_sync: datetime | None`, `in_progress: bool`, `last_result: dict[str, SyncResultSchema] | None`, `last_error: str | None`
   - `SyncTriggerResponse`: `message: str`, `status: str` ("started" or "already_in_progress")
2. Create `src/app/schemas/__init__.py` (empty if not exists)
3. Create `src/app/api/__init__.py` (empty if not exists)
4. Create `src/app/api/sync.py` with FastAPI router:
   - `router = APIRouter(prefix="/api/sync", tags=["sync"])`
   - `GET /api/sync/status` → returns SyncStatusSchema from get_sync_status()
   - `POST /api/sync/trigger` → triggers manual sync:
     - Check if sync already in_progress → return 409 with "already_in_progress"
     - Run `run_full_sync(settings)` as a background task (FastAPI BackgroundTasks)
     - Return 202 with "started" immediately (don't wait for sync to complete)
   - `POST /api/sync/historical` → triggers historical score sync:
     - Same in_progress check
     - Run `run_historical_sync(settings)` as background task
     - Return 202 with "started"
5. Update `src/app/main.py`:
   - Import sync router: `from app.api.sync import router as sync_router`
   - `app.include_router(sync_router)`

Use `from fastapi import BackgroundTasks` for async background execution of manual trigger. This is appropriate for one-off triggered tasks (vs APScheduler for periodic).

Do NOT add authentication to these endpoints — per PROJECT.md, no auth in v1.
