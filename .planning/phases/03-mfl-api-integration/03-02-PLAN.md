   - Calls `client.league()` and parses with `MFLLeagueResponse`
   - For each `MFLFranchise`:
     - Upsert into Team table using `franchise_id` as the match key
     - Use `select().where(Team.franchise_id == franchise.id)` to find existing
     - If exists: update name, conference, division
     - If new: insert new Team record
     - Use `session.flush()` after each upsert (not commit — let caller control transaction)
   - Return a `SyncResult` dataclass: `created: int`, `updated: int`, `errors: list[str]`
   - Log each create/update at INFO level using `logging.getLogger(__name__)`

Note: MFL may not provide conference/division in the franchise data. If missing, set to empty string and log a warning — these can be populated from league config later or manually.

Do NOT call `session.commit()` — the orchestration layer handles transaction boundaries.

  <name>Task 2: Create player sync service</name>
  <files>src/app/services/player_sync.py</files>
  <action>
1. Create `src/app/services/player_sync.py` with:
   - `async def sync_players(client: MFLClient, session: AsyncSession) -> SyncResult`
   - Calls `client.players()` and parses with `MFLPlayersResponse`
   - MFL returns thousands of players. Batch process efficiently:
     - Fetch all existing players in one query: `select(Player.mfl_id, Player.id).all()` → build lookup dict
     - For each `MFLPlayer`, transform to DB fields:
       - `mfl_id`: int(player.id)
       - `name`: player.name
       - `position`: player.position
       - `nfl_team`: player.team if not empty string else None
       - `birthdate`: parse player.birthdate (MFL uses epoch seconds as string) → date, or None
       - `draft_year`: int(player.draft_year) if present else None
       - `draft_round`: int(player.draft_round) if present else None
     - If mfl_id in lookup: update changed fields only (skip if no changes for efficiency)
     - If new: create Player record
     - Use `session.add_all()` for new players, batch in groups of 500
     - Use `session.flush()` after each batch
   - Return SyncResult with created/updated/error counts
   - Log summary at INFO level: "Synced {n} players: {created} new, {updated} updated"

MFL birthdate is epoch seconds as a string (e.g., "631238400"). Convert with `datetime.fromtimestamp(int(birthdate), tz=UTC).date()`. If empty or "0", set None.

Do NOT sync every player in MFL's database — MFL has 50k+ historical players. Only sync players that are on current rosters or are relevant. For now, sync ALL players (we'll optimize later if needed), but log the count so we know the volume.

Do NOT call session.commit() — orchestration layer handles this.
