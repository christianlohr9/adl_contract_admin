<task type="auto">
  <name>Task 1: Scaffold Vite + React 19 + TypeScript + Tailwind v4 + shadcn/ui</name>
  <files>frontend/package.json, frontend/vite.config.ts, frontend/tsconfig.json, frontend/tsconfig.app.json, frontend/src/index.css, frontend/src/main.tsx, frontend/components.json</files>
  <action>
1. Create the frontend project at `frontend/` using Vite React-TS template:
   ```
   npm create vite@latest frontend -- --template react-ts
   ```
2. Install dependencies:
   ```
   cd frontend && npm install react-router-dom
   npm install -D tailwindcss @tailwindcss/vite
   ```
3. Configure vite.config.ts: add tailwindcss() plugin and `@` path alias (resolve.alias pointing to ./src).
4. Replace src/index.css content with Tailwind v4 CSS-first config:
   ```css
   @import "tailwindcss";
   ```
   Do NOT use `@tailwind base/components/utilities` (that's v3). Do NOT create tailwind.config.js (v4 uses CSS-first @theme).
5. Run `npx shadcn@latest init` to set up shadcn/ui — this configures components.json, adds cn() utility, and sets up the @/ path alias in tsconfig.
6. Add shadcn/ui components needed for layout:
   ```
   npx shadcn@latest add sidebar tabs button card
   ```
7. Clean up Vite boilerplate: remove App.css, replace App.tsx with minimal placeholder, remove logo SVG.
8. Verify: `npm run dev` starts without errors, `npm run build` succeeds.
  </action>
  <verify>cd frontend && npm run build — exits 0 with no TypeScript errors</verify>
  <done>frontend/ exists with Vite + React 19 + TS + Tailwind v4 + shadcn/ui configured, dev server starts, build succeeds</done>
</task>
