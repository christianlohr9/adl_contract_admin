  <action>
  Replace `sync_historical_scores()` with a version that fetches weeks 1-17 AND YTD per season (not just YTD). Add gap detection so only missing (season, week) combos are fetched.

  Specifically:
  1. Add `detect_score_gaps(session, years)` function that queries PlayerScore table for each year to find which weeks (YTD + 1-17) are missing. Return `dict[int, list[str]]` mapping year -> list of missing week strings.

  2. Rewrite `sync_historical_scores()` to:
     - Accept same signature (client_factory, session, years)
     - Call `detect_score_gaps()` first to find what's missing
     - For each year with gaps, create a year-scoped client and call `sync_scores()` for each missing week
     - Respect rate limits: use `asyncio.sleep(client._request_delay)` between requests (MFL rate limits are per-IP across all year-scoped clients)
     - Log what gaps were detected and what was synced
     - Return `dict[int, SyncResult]` aggregating results per year

  3. Expected weeks per season: "YTD" + "1" through "17" = 18 total records per player per season.

  AVOID: Fetching all 18 weeks if they already exist — gap detection prevents redundant API calls.
  AVOID: Parallel year fetches — MFL rate limits are per-IP, sequential with delays is required.
  AVOID: Changing the `sync_scores()` function signature — it already works for any (season, week).
  </action>
