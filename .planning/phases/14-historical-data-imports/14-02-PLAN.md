<task type="auto">
  <name>Task 1: Create backfill orchestrator with BackfillStatus tracking</name>
  <files>src/app/services/historical_sync.py</files>
  <action>
  Create a new `historical_sync.py` module that orchestrates the full historical backfill and tracks completeness status.

  1. Define `BackfillStatus` dataclass:
     ```
     @dataclass
     class BackfillStatus:
         in_progress: bool = False
         scores_complete: bool = False
         contracts_complete: bool = False
         missing_score_years: list[int] = field(default_factory=list)
         missing_contract_years: list[int] = field(default_factory=list)
         started_at: datetime | None = None
         completed_at: datetime | None = None
         error: str | None = None
     ```

  2. Create module-level `_backfill_status = BackfillStatus()` with getter `get_backfill_status()`.

  3. Create `run_historical_backfill(settings: Settings)` async function:
     - Set `in_progress = True`, `started_at = now()`
     - Open a single async_session
     - Call `detect_score_gaps(session, settings.sync_historical_years)` to find missing score weeks
     - Call `detect_contract_gaps(session, settings.sync_historical_years)` to find missing contract years
     - Update `missing_score_years` and `missing_contract_years` on status
     - If no gaps: set both `_complete = True`, `in_progress = False`, log "no gaps", return early
     - If score gaps: call `sync_historical_scores(client_factory, session, years_with_gaps)`
     - Commit after scores
     - If contract gaps: call `run_historical_roster_sync` logic inline (create client per year, call sync_rosters)
       - Actually, use the `client_factory` pattern directly here rather than calling run_historical_roster_sync from orchestrator, since we want a single session and single transaction per phase
     - Commit after contracts
     - Set status flags on completion
     - Wrap in try/except: on error, set `error` field, log exception, set `in_progress = False`

  4. Import `detect_score_gaps` from score_sync, `detect_contract_gaps` from roster_sync, `sync_historical_scores` from score_sync, `sync_rosters` from roster_sync, `MFLClient` from mfl.client.

  AVOID: Blocking on backfill — this function will be called via asyncio.create_task().
  AVOID: Using APScheduler for the one-shot backfill — asyncio.create_task is simpler.
  AVOID: Creating separate sessions per year — use one session for the whole backfill, commit after each phase (scores, then contracts).
  </action>

  Verify BackfillStatus has all expected fields.
  </verify>
  <done>

  - `run_historical_backfill()` orchestrates score + contract backfill
  - Gap detection runs before fetching
  - Status tracking updated throughout execution
  - Error handling captures failures without crashing
  </done>
