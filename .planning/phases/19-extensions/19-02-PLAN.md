**Known gaps in current EPV code (expect these to cause discrepancies):**

1. **PR Starter Floor not applied to EPV_old** — `epv.py:257` has comment "Floor PR_old at PR Starter Floor (if available — for now use raw)". The spreadsheet floors PRpreviousR at the starter floor (e.g., LB with Tot=51 gets Fin=38). The function `_calculate_pr_starter_floor` exists in `buyouts.py` but is not used in `epv.py`.

2. **Position rank uses only Total Points** — `get_position_rank` in `epv.py` ranks by total points only. Bylaws say PR = "The higher rank of (1) ADL Total Points rank and (2) ADL PPG rank". Spreadsheet shows both Tot and Avg columns, with Fin = MIN(Tot, Avg) (lower number = better rank), then floored at starter floor.

3. **PR Starter Floor values by position** (from spreadsheet PRcurrentNR Fin column):
   QB=16, RB=28, WR=50, TE=18, PK=16, PN=16, DT=38, DE=40, LB=38, CB=38, S=38

  <name>Task 1: Fix EPV calculation gaps</name>

  <action>
Fix the three known gaps in EPV calculation:

**1. Add PPG-based position rank:**
Add a `get_position_rank_ppg` function (or modify `get_position_rank`) that also computes rank by points-per-game (PPG = total_points / active_weeks). The final PR should be MIN(total_rank, ppg_rank) — i.e., the better (lower number) of the two rankings.

PPG calculation: For each player at the position in the season, compute total_points / count_of_numeric_weeks. Rank by PPG descending (dense_rank). The player's PPG rank is their position in this ranking.

**2. Apply PR Starter Floor:**
Move or copy `_calculate_pr_starter_floor` from `buyouts.py` into a shared location (either `epv.py` or `rules.py`). Apply it in `calculate_epv`:
- EPV_old (PRpreviousR): Floor PR at starter floor — `pr_old = min(pr_old_raw, starter_floor)`
- EPV_curr (PRcurrentNR): Floor PR at starter floor — same logic
- EPV_new (PRrecentR): Spreadsheet does NOT appear to floor PRrecentR in most cases (Fin often equals the actual rank), but verify — if Fin differs from MIN(Tot,Avg) and equals starter floor, apply floor there too.

Based on spreadsheet data: ALL three PR types appear to be floored at starter floor (D. Bush PRcurrentNR Fin=38 with no Tot/Avg data = floor applied; PRpreviousR Fin=38 when Tot=51,Avg=66 = floor applied).

**3. Store PR Starter Floor constants:**
Either compute dynamically (like buyouts.py does from PlayerScore data) or add to contracts.json. The buyouts.py approach is correct — reuse that function. Make it importable from a shared location.

Avoid: Don't hardcode the floor values — they're derived from league data and change yearly.
