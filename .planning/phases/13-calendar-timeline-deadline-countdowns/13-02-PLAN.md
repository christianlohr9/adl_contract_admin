**useDeadlineCards.ts** — Custom hook that derives countdown card data:

```typescript
interface DeadlineCard {
  action: string;
  label: string;
  daysRemaining: number;
  urgency: "green" | "yellow" | "red";
  dateLabel: string;        // "Closes Mar 15" or "Opens Mar 20"
  eligibleCount: number;
  isOpening: boolean;       // true = "opens in X days", false = "X days remaining"
}
```

Logic:
1. Accept `windowStatuses: Record<string, WindowStatusSchema>` and `actionGroups: ActionGroupSchema[]`
2. For each window status entry (skip `proven_performance_escalator` — no deadline per Phase 10 decision):
   - If status === "open" AND closes !== null: compute days to closes date. If daysRemaining > 0, create card with isOpening=false.
   - If status === "closed" AND opens !== null: compute days to opens date. If daysRemaining > 0, create card with isOpening=true (window opens soon).
   - Skip "unconfigured" statuses and past dates.
3. Get eligible count from matching action_group's players.length (0 if no matching group).
4. Sort by daysRemaining ascending (most urgent first).
5. Return array of DeadlineCard via useMemo.

Date math: Use `getDaysRemaining(dateStr)` helper — `new Date(dateStr + "T00:00:00")` for local timezone, `setHours(0,0,0,0)` on now, `Math.ceil((target - now) / 86400000)`.

Urgency: `days <= 7 → "red"`, `days <= 14 → "yellow"`, else `"green"`. Opening windows always use "green" (not urgent — just informational).

Action labels reuse from WindowStatusBar: Extensions, Franchise Tags, ERFA Tenders, RFA Tenders, Buyout/Restructure, 5th Year Option.

**DeadlineCountdown.tsx** — Component that renders cards:

1. Accept same props as useDeadlineCards (windowStatuses + actionGroups).
2. Call useDeadlineCards to get cards array.
3. If empty: render "No upcoming deadlines" message in a muted text block.
4. Render responsive grid of cards (`grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-3`).
5. Each card: rounded border with urgency-colored border/background (follow RESEARCH.md urgencyStyles pattern), label at top, large "X days" number, small date label below, small "N eligible" hint if eligibleCount > 0.
6. Opening windows show "Opens in X days" instead of "X days remaining".

**Do NOT** use setInterval or real-time ticking — day-level display only updates on data refetch.
**Do NOT** add a separate calendar API fetch — all data comes from existing eligibility response.
