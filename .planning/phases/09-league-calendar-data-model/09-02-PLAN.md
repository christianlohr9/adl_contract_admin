Create CalendarPage.tsx with these elements:

**Season selector at top:**
- Input or select for season year (default to current year 2026)
- "Load" button to fetch existing calendar for that season
- "New Season" button to create a blank calendar entry

**Date entry form grouped into cards:**
Use shadcn Card components. Group fields by category matching the model:

**Card 1: "Extension Deadlines"**
- oEXT Deadline (date input)
- iEXT Window Start (date input)
- iEXT Window End (date input)

**Card 2: "Tag & Tender Deadlines"**
- Franchise Tag Deadline (date input)
- RFA/ERFA Tender Deadline (date input)

**Card 3: "Other Deadlines"**
- B/R Deadline (date input)
- 5th Year Option Deadline (date input)
- Rookie Signing Deadline (date input)
- Salary Rankings Date (date input)

**Card 4: "Auctions"**
- R/F Auction: Start + End (two date inputs per row)
- FT Auction: Start + End
- RFA Auction: Start + End
- B/R Auction: Start + End
- Rookie Draft: Start + End
- UDFA Auction: Start + End
- UFA Auction: Start only (no end — continuous)

**Card 5: "Season Markers"**
- Regular Season Start (date input)
- Regular Season End (date input)

**Form behavior:**
- Use native HTML `<input type="date">` for date fields — simple, works everywhere, no extra dependency needed. Style with Tailwind to match shadcn aesthetic (rounded border, focus ring, etc.)
- On page load with a season, call `useCalendar(season)` to populate existing dates
- "Save" button at bottom:
  - If calendar doesn't exist for this season: call `useCreateCalendar` mutation
  - If calendar exists: call `useUpdateCalendar` mutation
- Show success toast or inline success message on save
- Show loading state while fetching/saving

**Labels:** Use readable labels (not field names). Example: "Offseason Extension Deadline" not "oext_deadline". Include helper text where useful (e.g., "Before NFL Combine" for oEXT).

Do NOT install a date picker library — native date inputs are sufficient for an admin form used by one person.
