**Pydantic schemas (src/app/schemas/calendar.py):**

Create 3 schemas:
1. `SeasonCalendarSchema` — response model, all fields, `model_config = ConfigDict(from_attributes=True)`
2. `SeasonCalendarCreateSchema` — create input: `season: int` required, all date fields as `date | None = None`
3. `SeasonCalendarUpdateSchema` — update input: all date fields as `date | None = None` (no season — that's the path param)

Import `date` from datetime, `ConfigDict` from pydantic.

**FastAPI endpoints (src/app/api/calendar.py):**

Create router with `prefix="/api/calendar"`, `tags=["calendar"]`.

4 endpoints:
1. `GET /api/calendar/` — list all season calendars, ordered by season desc. Returns `list[SeasonCalendarSchema]`.
2. `GET /api/calendar/{season}` — get calendar for specific season. 404 if not found. Filter by `SeasonCalendar.season == season`.
3. `POST /api/calendar/` — create new season calendar. Check for existing season first (409 Conflict if duplicate). `session.add()` + `session.commit()` + `session.refresh()`. Return 201.
4. `PUT /api/calendar/{season}` — update existing season calendar. 404 if not found. Apply only non-None fields from the update schema using `setattr()` loop. `session.commit()` + `session.refresh()`.

Follow established patterns from teams.py and cap.py — use SessionDep, raise HTTPException for 404/409.

**Register router in main.py:**

Add `from app.api.calendar import router as calendar_router` and `app.include_router(calendar_router)` alongside existing router registrations.

**Extend API client (src/app/api/client.ts):**

Add `post` and `put` methods to the api object following the same pattern as `get`:
```typescript
async function post<T>(path: string, body: unknown): Promise<T> {
  const res = await fetch(`${BASE_URL}${path}`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(body),
  });
  if (!res.ok) {
    throw new Error(`API error: ${res.status} ${res.statusText}`);
  }
  return res.json() as Promise<T>;
}

async function put<T>(path: string, body: unknown): Promise<T> {
  const res = await fetch(`${BASE_URL}${path}`, {
    method: "PUT",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(body),
  });
  if (!res.ok) {
    throw new Error(`API error: ${res.status} ${res.statusText}`);
  }
  return res.json() as Promise<T>;
}

export const api = { get, post, put };
```
