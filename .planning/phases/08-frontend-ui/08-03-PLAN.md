  <name>Task 2: Contract tools comparison view with all 6 tabs</name>
  <files>frontend/src/components/player/tools/ExtensionsTab.tsx, frontend/src/components/player/tools/TagsTab.tsx, frontend/src/components/player/tools/TendersTab.tsx, frontend/src/components/player/tools/BuyoutTab.tsx, frontend/src/components/player/tools/FifthYearTab.tsx, frontend/src/components/player/tools/PPETab.tsx, frontend/src/pages/PlayerDetailPage.tsx</files>
  <action>
1. Create tool tab components in `frontend/src/components/player/tools/`:

   **ExtensionsTab.tsx** — receives ExtensionResultSchema | null:
   - If null or not eligible: show Alert with ineligibility_reason
   - If eligible: render table of extension options with columns: Extension Years, EYS, Smoothed Salary (formatted), Total Value (formatted), Contract Type, Years After
   - Use shadcn Table (not DataTable — these are small, no pagination needed)

   **TagsTab.tsx** — receives TagResultSchema | null:
   - If null or not eligible: show Alert with ineligibility_reason
   - If eligible: show consecutive_tag_count info, render table of tag options: Tag Type, Salary (formatted), Opening Bid (formatted, if present), Contract Years, Guarantee Level, Compensation

   **TendersTab.tsx** — receives TenderResultSchema | null:
   - Show ERFA section if erfa_eligible with erfa_option details
   - Show RFA section if rfa_eligible with table of rfa_options: Tender Type, Salary (formatted), Contract Years, Compensation
   - If neither eligible: show Alert with ineligibility_reasons joined

   **BuyoutTab.tsx** — receives BuyoutResultSchema | null:
   - If null or not eligible: show Alert with ineligibility_reason
   - If eligible: show Opening Bid (formatted), salary tiers table (Contract Years, Salary formatted), GM options list (action, description, salary if present, contract years if present)

   **FifthYearTab.tsx** — receives FifthYearOptionSchema | null:
   - If null or not eligible: show Alert with ineligibility_reason
   - If eligible: show Percentile Tier, Salary (formatted), Guarantee Level

   **PPETab.tsx** — receives PPESchema | null:
   - If null or not eligible: show Alert with ineligibility_reason
   - If eligible: show Current Salary vs Escalator Salary comparison, Escalator Level

2. Update PlayerDetailPage.tsx:
   - Replace placeholder tab content with real tool components
   - Pass tools data from usePlayerTools to each tab: tools.extensions → ExtensionsTab, tools.tags → TagsTab, tools.tenders → TendersTab, tools.buyout → BuyoutTab, tools.fifth_year_option → FifthYearTab, tools.ppe → PPETab
   - Show loading state in tabs while tools data loads
   - Each tab shows "Not available" Alert when the tool data is null (player not eligible)

Design notes:
- Keep it clean — numbers are the star, not chrome
- Format ALL salary values with formatSalary
- Use consistent Alert styling for ineligibility across all tabs
- Tables should be compact with minimal columns — only show what a GM needs to make a decision
