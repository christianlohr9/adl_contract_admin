     - envVars: VITE_API_URL (sync: false — set to backend URL after deploy). Note: this is a build-time variable, must be set before first build.

  Use the Render Blueprint spec format. Do NOT include repo URL or branch — Render infers these from the connected GitHub repo.
  </action>
  <verify>`cat render.yaml` shows valid YAML with both services defined, no hardcoded secrets</verify>
