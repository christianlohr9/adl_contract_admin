<task type="checkpoint:human-action" gate="blocking">
  <action>Create Neon database and Render services, then configure environment variables</action>
  <instructions>
  **Step 1: Create Neon PostgreSQL database**
  1. Go to https://neon.tech and sign up (free, GitHub login works)
  2. Create a new project (name: `adl-contract-admin`, region: closest to US West / Oregon)
  3. Copy the connection string — it looks like: `postgresql://user:pass@ep-xxx.us-east-2.aws.neon.tech/dbname?sslmode=require`
  4. For SQLAlchemy async, change `postgresql://` to `postgresql+asyncpg://` in the string

  **Step 2: Create Render services**
  1. Go to https://render.com and sign up (free, GitHub login works)
  2. Connect your GitHub repo (`adl_contract_admin`)
  3. Option A (recommended): Use "Blueprints" → New Blueprint Instance → select the repo → Render reads `render.yaml` and creates both services
  4. Option B (manual): Create a "Web Service" (Docker, free plan) for backend + "Static Site" (free) for frontend

  **Step 3: Configure environment variables**

  *Backend (adl-api) env vars:*
  | Variable | Value |
  |----------|-------|
  | DATABASE_URL | `postgresql+asyncpg://...` (Neon connection string with asyncpg) |
  | CORS_ORIGINS | `https://adl-frontend-XXXX.onrender.com` (frontend URL from Step 2) |
  | MFL_LEAGUE_ID | `60206` |
  | MFL_YEAR | `2026` |
  | MFL_API_KEY | Your MFL API key |
  | MFL_USERNAME | Your MFL username |
  | MFL_PASSWORD | Your MFL password |
  | SYNC_ENABLED | `false` (production uses GitHub Actions cron, not in-app scheduler) |

  *Frontend (adl-frontend) env vars:*
  | Variable | Value |
  |----------|-------|
  | VITE_API_URL | `https://adl-api-XXXX.onrender.com` (backend URL from Step 2) |

  **Step 4: Configure GitHub Actions secret**
  1. Go to your GitHub repo → Settings → Secrets and variables → Actions
  2. Add secret: `API_URL` = `https://adl-api-XXXX.onrender.com` (backend URL)

  **Step 5: Trigger deploy**
  - If using Blueprints, deploy starts automatically
  - If manual, trigger a deploy on both services
  - Wait for both deploys to complete (backend may take 2-3 minutes, frontend ~1 minute)
  </instructions>
  <verification>Both Render services show "Live" status in dashboard</verification>
  <resume-signal>Paste the backend and frontend URLs when both are live (e.g., "backend: https://adl-api-xxx.onrender.com frontend: https://adl-frontend-xxx.onrender.com")</resume-signal>
</task>
