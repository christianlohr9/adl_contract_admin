Run a comprehensive eligibility check across ALL players on ALL 32 teams to verify no false positives or false negatives remain.

**Sweep approach:**
1. Query the database for all teams (GET /api/teams or direct DB query)
2. For each team, get all rostered players (GET /api/teams/{team_id}/players or DB query)
3. For each player, hit GET /api/tools/{player_id}/eligibility to get all 7 action results
4. Categorize results and check for anomalies:
   - Players marked eligible who shouldn't be (false positives)
   - Players marked ineligible with suspicious reasons (potential false negatives)
   - Unexpected errors or missing data

**Anomaly detection rules:**
- Extension eligible but years_remaining >= 2 → false positive
- Tag eligible but years_remaining > 0 → false positive
- ERFA eligible but salary above veteran minimum → false positive
- 5YO eligible but not round 1 → false positive
- PPE eligible but not rounds 2-5 → false positive
- Any eligibility check returning an error → investigate

**Create 15-VALIDATION.md with:**
- Total players checked
- Results summary by action (eligible count / ineligible count / error count)
- Any anomalies found (with player ID, name, expected vs actual)
- Anomaly resolution (if fixable, fix and re-validate)
- Final confidence statement

**If anomalies are found:**
- Fix the underlying issue
- Re-run the affected checks
- Document the fix in 15-VALIDATION.md
