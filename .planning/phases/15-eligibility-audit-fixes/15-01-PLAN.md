Read rules/docs/contract_tools.md (bylaws source of truth) and each eligibility service file. For every bylaw rule, document:
1. The exact bylaws text
2. The code that implements it (file:line reference)
3. Whether the implementation matches (MATCH / DISCREPANCY / MISSING)

Audit each of the 7 contract actions systematically:

**1. Extensions (rules/docs/contract_tools.md Section X-A → extensions.py)**
Audit these eligibility rules:
- Players with Contract Years >= 2 are ineligible
- Players on rookie contracts signed for less than max years are ineligible (4 for drafted, 3 for UDFA) — check that UDFA contracts are detected and use max=3 (not just drafted rookies with max=4)
- Players who received EXT in current or prior window are ineligible — check the EXT detection query logic (signed_season >= season - 1)
- Players with no Robust PRs are ineligible — check the 3-season lookback (current + 2 prior)
- EXT cannot cause years to exceed 6-year maximum
- NFL kickoff gating for rookies in final year — document as "Phase 16, out of scope"
- EYS formula: MAX(EPV_curr, EPV_new, EPV_old, floor) × (1.15 - 0.05 × ext_years)
- Floor: 75% active salary / 82.5% expired salary
- All EXTs are SD contracts, floored at SD minimum

**2. Franchise Tags (Section X-B → franchise_tags.py)**
Audit these eligibility rules:
- Player must have 0 years remaining (expired contract)
- Max 3 consecutive EFT/NEFT tags — check count logic (4th tag blocked, 3rd tag at premium)
- 1 franchise tag per team per season — check allotment integration
- Tag salary: EFT/NEFT = MAX(AVG(Top5), 120% prev), TT = MAX(AVG(Top10), 120% prev)
- Third consecutive tag premium: MAX(144% prev tag, 120% positional FT, highest positional FT)
- PK/PN position grouping into single "Kicker/Punter" category — check if implemented
- Opening bid for NEFT/TT: MAX(CEIL_100K(SD_Min - $100k), FLOOR_100K(tag_salary))
- All tag salaries rounded to nearest $10k

**3. RFA Tenders (Section X-C → tenders.py)**
Audit these eligibility rules:
- Player must have 0 years remaining
- Contract must not be 4+ years old
- Contract must not include ineligible types from 2021 or earlier (EFT, NEFT, TT, NEFToff, TToff, FRFA, SRFA, ORFA, RRFA, B/R, EXT, 5YO)
- Must not be expired multi-year UFA from 2023 or earlier — check original_length calculation
- 2 tenders per team shared with ERFA
- Opening bid formulas: FRFA (2.2x), SRFA (1.65x), ORFA (1.1x), RRFA (NFL price only)
- All figures rounded down to nearest $100k
- NFL RFA prices — check if placeholder zeros are causing incorrect bids
- Must not be a previous RFA contract — check if this rule exists in code

**4. ERFA Tenders (Section X-D → tenders.py)**
Audit these eligibility rules:
- Player must have 0 years remaining
- Previous contract signed at or below veteran minimum in one of previous two league years
- Expired contract must not be an ERFA contract
- Salary: MAX(Veteran Minimum, 110% of previous salary)
- 1-year contract, no auction
- 2 tenders shared with RFA

**5. Buyout/Restructure (Section X-E → buyouts.py)**
Audit these eligibility rules:
- Any player with a contract is eligible EXCEPT rookies/UDFA not in final year
- "Including the fifth year if 5YO has been exercised" — check 5YO handling
- 1 B/R per team per season
- Opening bid: SD minimum rounded up to $100k
- Salary: high_bid × (1 - 0.05 × (years - 1)), floored at SD minimum
- Revert/Transfer prohibited for tagged players on expired contracts — check if implemented
- Salary cap penalty rules for Restructure/Buyout options

**6. Fifth Year Option (eligibility.py inline + buyouts.py)**
Audit these eligibility rules:
- First-round drafted rookies only
- Must be in 4th year of rookie contract
- 5YO not already exercised
- Salary tiers by performance percentile (top 87.5%, 75-87.5%, 25-75%, bottom 25%)
- FG guarantee level
- Deadline: July 1 (fyo_deadline)

**7. Proven Performance Escalator (eligibility.py inline + buyouts.py)**
Audit these eligibility rules:
- Rounds 2-5 drafted rookies
- PK/PN ineligible
- Must be in 4th year of contract
- Escalator tiers: top 75% = SRFA price, below 75% = ORFA price
- Automatic (no deadline/window)
- Only applies if escalator salary exceeds current salary

**Also audit cross-cutting concerns:**
- Window gating (window_status.py): verify each action maps to correct calendar fields
- Allotment limits (allotments.py): verify limits match bylaws (1 FT, 1 B/R, 2 RFA/ERFA shared)
- Contract query patterns: verify active vs expired contract lookups are correct for each action

Write 15-AUDIT.md with sections for each action containing:
- Rule-by-rule mapping table (Bylaw Rule | Code Reference | Status | Notes)
- Discrepancy detail for any DISCREPANCY or MISSING items
- Recommended fix for each discrepancy
