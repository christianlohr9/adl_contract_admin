## Milestone Summary

**Decimal Phases:** None

**Key Decisions:**
- Tag salaries use ADL Cap Percentage: (current_cap / prev_cap) × AVG(top_N) — discovered from spreadsheet formula, not in bylaws
- Performance salary uses prior season (End25 Sal) salaries × 1.1, not current season contract table
- Conference-scoped accrued seasons with 6-week threshold from weekly roster scans
- PPE price = raw NFL RFA tag price (SRFA or ORFA), NOT the tender MAX formula
- Players below PR Starter Floor get NO PPE escalation — bylaws say "above his PR Starter Floor"
- Direct DB access for CLI validation — faster than HTTP API, doesn't require running server

**Issues Resolved:**
- ISS-018-001: RESOLVED — weekly roster scans from 2016 provide complete data; contracts table used as roster source; salary column widened for R/F auction values
- FT pricing mismatch — discovered and implemented ADL Cap Percentage adjustment
- EPV performance salary methodology — corrected from current-season to prior-season × 1.1
- PPE below-floor false positives — added exclusion for players ranked below PR Starter Floor
- 5YO percentile formula and tier boundary corrections

**Issues Deferred:**
- None — all v1.3 scope items resolved

**Technical Debt Incurred:**
- Validation scripts in scripts/ directory (temporary, not production code)
- Some hardcoded 2026 season references in validation scripts
