# Milestone v1.2: Data Integrity & Eligibility Accuracy

**Status:** ✅ SHIPPED 2026-03-13
**Phases:** 14-17
**Total Plans:** 8

## Overview

Import missing historical data from MFL and systematically audit/fix all eligibility logic against bylaws to eliminate false positives and false negatives. Culminated in a full regression validation sweep across all 32 teams with zero anomalies.

## Phases

### Phase 14: Historical Data Imports

**Goal**: Pull past-season player scores and contract history from MFL API to enable accurate eligibility checks
**Depends on**: v1.1 complete
**Plans**: 4 plans (2 feature + 2 fix)

Plans:
- [x] 14-01: Historical Sync Services (weekly scores + roster/contract sync + gap detection)
- [x] 14-02: Startup Backfill & Status Tracking (lifespan integration + status API)
- [x] 14-FIX: Rate limit retry + backfill resilience (UAT-001, UAT-002)
- [x] 14-FIX2: Rate limit compliance + status fix (UAT-003, UAT-004)

**Details:**
- Extended score sync to fetch all 18 week variants (YTD + 1-17) per season with gap detection
- Contract gap detection queries DB before fetching to avoid redundant API calls
- Non-blocking startup backfill via asyncio.create_task() with BackfillStatus tracking
- GET /api/sync/backfill-status and POST /api/sync/backfill endpoints
- MFLRateLimitError added to tenacity retry with exponential backoff (4-60s, 10 attempts)
- Per-year commit pattern: partial progress survives failures
- Adaptive rate limiting: 6s backfill delay vs 1s normal, 30s inter-year cooldown

## Milestone Summary

**Key Decisions:**
- Gap detection before fetch to avoid redundant MFL API calls
- asyncio.create_task() for non-blocking startup backfill (not APScheduler for one-shot)
- Audit-only approach first: catalog all issues before fixing any
- 2026 NFL CBA RFA tender prices from official sources (not placeholder zeros)
- Active-contract check to prevent tag/tender eligibility for re-signed players
- Kickoff check placed inside rookie/UDFA block only — veterans unaffected
- Direct DB access for CLI validation script (faster than HTTP API)

**Issues Resolved:**
- UAT-001 (Phase 4): Missing NFL kickoff eligibility rule — resolved by Phase 16
- ISSUE-001 (Phase 8): Extension eligibility needs historical player scores — resolved by Phase 14
- ISSUE-002 (Phase 8): Tags/tenders need multi-season contract history — resolved by Phase 14
- UAT-001/002 (Phase 14): MFL rate limit retry and backfill failure — resolved by 14-FIX
- UAT-003/004 (Phase 14): Rate limit compliance and completed_at tracking — resolved by 14-FIX2
- 97 false positives: re-signed players showing as tag/tender eligible — resolved by 15-02
- 12 eligibility discrepancies and 3 missing implementations — all resolved by 15-02

**Issues Deferred:**
- Calendar timeline visualization (visual period rendering) — deferred to future milestone

**Technical Debt Incurred:**
- Phase 15 baseline counts hardcoded in validation script for delta comparison
- CLI scripts use sys.path.insert hack for src/ imports
